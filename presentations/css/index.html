CSS Animations

Создание плавных и интерактивных эффектов с помощью CSS

Анимируемые свойства CSS

В CSS большинство свойств можно анимировать.

Это означает, что их значения могут плавно изменяться во времени, а не переключаться мгновенно.

width: 100px
→
width: 300px
transition и animation позволяют управлять этим изменением во времени.

Transition: плавное изменение

Без transition

button {
  background: #eaf4ff;
}

С transition

button {
  transition:
    background 0.4s,
    color 0.4s;
}
Разница: без transition изменение происходит мгновенно, а с ним — плавно.

Как изменяются значения

Браузер автоматически вычисляет промежуточные значения между начальным и конечным состояниями.

Например, при перемещении элемента от 0px до 100px браузер создаёт промежуточные положения.

0px 50px 100px
0px
→
100px
Браузер делает работу за нас. Разработчику достаточно задать начальное и конечное значение — промежуточные состояния будут рассчитаны автоматически.

Transition и Animation

Оба механизма позволяют плавно изменять CSS-свойства, но используются для разных сценариев.

transition

Плавный переход между двумя состояниями. 

button {
  transition: transform 0.3s;
}

button:hover {
  transform: scale(1.1);
}

animation

Последовательность нескольких состояний. 

@keyframes move {
  from { left: 0; }
  to   { left: 200px; }
}

.box {
  animation: move 2s infinite;
}

Что такое CSS Transition

CSS Transition позволяет сделать изменение свойств элемента плавным.

Без transition

.box {
  left: 20px;
  width: 70px;
}

.box.active {
  left: 220px;
  width: 110px;
}

С transition

.box {
  left: 20px;
  width: 70px;
  transition:
    left 0.7s,
    width 0.7s;
}

.box.active {
  left: 220px;
  width: 110px;
}

Как работает Transition

Transition всегда работает между двумя состояниями элемента: начальным и конечным.

Реальный пример

opacity: 1 
.box {
  opacity: 1;
  transition: opacity 1s;
}

.box.hidden {
  opacity: 0;
}

Что происходит?

opacity: 1
Начало
→
opacity ≈ 0.5
Промежуточное
→
opacity 0
Конец
Браузер сам вычисляет значения между 1 и 0.

Свойство

transition-property
Длительность

Сколько времени занимает переход.

transition-duration
Задержка

Когда должен начаться переход.

transition-timing-function

Код

Что такое CSS Transform?

CSS Transform позволяет изменять внешний вид элемента без изменения его положения в структуре страницы.

С помощью transform можно

↔ Перемещать
↻ Поворачивать
⤢ Изменять размер
◇ Наклонять
▣ Выполнять 3D-преобразования

Главная особенность

transform
Пунктир показывает исходное положение.

Остальная страница при этом не перестраивается.

Основные свойства

Для работы с трансформациями чаще всего используются два свойства.

transform

Что изменяем?

Задаёт одно или несколько преобразований элемента. 

transform:
  translateX(50px);
transform-origin

Откуда преобразуем?

Определяет точку, относительно которой выполняется преобразование. 

transform-origin:
  left center;
По умолчанию точка преобразования находится в центре элемента.

Свойство transform

В одном свойстве можно объединить несколько преобразований.

transform: translateX(100px) rotate(30deg) scale(1.2);
translateX()
перемещение
rotate()
поворот
scale()
изменение размера
Важно: преобразования выполняются последовательно. Поэтому порядок записи влияет на результат.

Порядок преобразований имеет значение

Один и тот же набор операций в разном порядке даёт разный результат.

Сначала translate

transform:
  translateX(80px)
  rotate(30deg);
●
1
Сначала двигаемся вправо,
потом поворачиваем.

Сначала rotate

transform:
  rotate(30deg)
  translateX(80px);
●
2
Сначала поворачиваем систему координат,
потом двигаемся вдоль неё.
Главная мысль: translateX(80px) после поворота — это уже движение вдоль повёрнутой оси X.

Особенности Transform

Трансформации изменяют только отображение элемента, но не его место в потоке документа.

Исходный layout

A
B
C

После transform

A
B
C
Что произошло?
B визуально переместился, но A и C остались на своих местах. Место B в layout не изменилось.

Практический пример: выезжающее меню

Используем transform, чтобы меню плавно выезжало из-за края экрана.

MY WEBSITE
Главная страница
Меню
Главная Каталог О компании Контакты
Попробуй: нажми на ☰ — меню выедет справа.

Шаг 1. Создаём кнопку и меню

Сначала обычная HTML-разметка. Пока без анимации. 

<button class="menu-toggle">
  <span></span>
  <span></span>
  <span></span>
</button>

<aside class="menu">
  <strong>Меню</strong>

  <nav>
    <a href="#">Главная</a>
    <a href="#">Каталог</a>
    <a href="#">О компании</a>
    <a href="#">Контакты</a>
  </nav>
</aside>
Что здесь есть?
.menu-toggle — кнопка открытия
.menu — панель меню
.open — класс, который будем добавлять при открытии

Шаг 2. Размещаем меню справа

Используем position: fixed, чтобы меню было привязано к окну браузера.

.menu {
  position: fixed;
  top: 0;
  right: 0;
  width: 300px;
  height: 100vh;
  background: white;
}

Почему fixed?

Меню должно занимать всю высоту окна и оставаться привязанным к его правому краю. 

top: 0;
right: 0;
Пока меню просто находится справа и видно пользователю.

Шаг 3. Прячем меню за краем экрана

Теперь используем transform. 

.menu {
  ...

  transform: translateX(100%);
}

Что означает 100%?

Процент рассчитывается относительно ширины самого меню.

width: 300px
→ translateX(100%) = сдвинуть на 300px вправо
translateX(100%)

Меню полностью уезжает за правый край.

Сам элемент никуда не удаляется — мы просто визуально сдвигаем его.

Шаг 4. Как показать меню?

Нам нужно вернуть меню в его исходное положение.

.menu.open {
  transform: translateX(0);
}
translateX(100%)
меню скрыто
→
translateX(0)
меню видно
Получается два состояния:
🔴 обычное состояние → translateX(100%)
🟢 открытое состояние → translateX(0)

Шаг 5. Делаем движение плавным

Сейчас меню просто мгновенно перемещается. Добавим transition. 

.menu {
  transform: translateX(100%);

  transition:
    transform 0.35s ease;
}
transform
Определяет, где находится меню.
transition
Определяет, как плавно происходит изменение.
0.35s — длительность  ·  ease — функция изменения скорости

Шаг 6. Переключаем состояние

Осталось научиться добавлять класс open. 

const toggle =
  document.querySelector('.menu-toggle');

const menu =
  document.querySelector('.menu');

toggle.addEventListener('click', () => {
  menu.classList.add('open');
});

Что происходит при клике?

.menu
→
.menu.open
JavaScript не анимирует меню. Он только добавляет класс. Анимацию полностью описывает CSS.

Весь CSS для анимации

Теперь можно посмотреть на три ключевые части вместе.

.menu {
  position: fixed;
  top: 0;
  right: 0;

  width: 300px;
  height: 100vh;

  background: white;

  /* 1. Начальное положение */
  transform: translateX(100%);

  /* 2. Плавность */
  transition:
    transform 0.35s ease;
}

/* 3. Открытое состояние */
.menu.open {
  transform: translateX(0);
}

translateX(0)
показать

При наведении на текст появляются две линии. Попробуй навести курсор.

Hover for underline

<div class="hover-underline">
  Hover for underline
</div>
Здесь всего один элемент — эффект полностью создаётся с помощью CSS.

Как работает анимация?

Используем псевдоэлементы ::before и ::after как две линии.

.hover-underline {
  position: relative;
  display: inline-block;
}

.hover-underline::after,
.hover-underline::before {
  content: '';
  position: absolute;
  width: 100%;
  height: 2px;
  background:
    linear-gradient(to right, #ff0000, #00ffff
    );

  left: 0;
  transform: scaleX(0);
  transition:
    transform 0.4s ease-out;
}
::before
Верхняя линия
::after
Нижняя линия
.hover-underline::before {
  top: -5px;
  transform-origin: left;
}

.hover-underline::after {
  bottom: -5px;
  transform-origin: right;
}
Изначально: scaleX(0) — линия имеет нулевую ширину.

При наведении: scaleX(1) — линия возвращается к полной ширине. 
.hover-underline:hover::after,
.hover-underline:hover::before {
  transform: scaleX(1);
}

Структура: внешняя карточка → внутренний контейнер → две стороны карточки.

Как работает 3D-поворот?

Для эффекта переворота нужны несколько свойств. Разберём их по очереди.

perspective: 1000px;
Создаёт перспективу для 3D-преобразования.
transition: transform 0.6s;
Делает поворот плавным.
transform-style: preserve-3d;
Сохраняет дочерние элементы в 3D-пространстве.
rotateY(180deg)
Поворачивает карточку на 180° вокруг оси Y.

1. Внешняя карточка

.card {
  perspective: 1000px;
}

2. Внутренняя часть

.card-inner {
  transition: transform 0.6s;
  transform-style: preserve-3d;
}

3. Поворот при наведении

.card:hover .card-inner {
  transform: rotateY(180deg);
}
Главная идея: мы поворачиваем не переднюю и заднюю стороны отдельно, а весь .card-inner.

Что такое CSS Animation

CSS Animation позволяет создавать полноценные анимации без JavaScript.

Transition

Обычно описывает переход из одного состояния в другое.
начало → конец

Animation

Может содержать несколько промежуточных состояний.
начало → этап → этап → конец
Для создания CSS-анимации используются animation и @keyframes.

Как работает @keyframes

@keyframes описывает, что должно происходить с элементом во время анимации. 

@keyframes move {
  from {
    left: 0;
  }

  to {
    left: 200px;
  }
}
from — начальное состояние
to — конечное состояние

Первая CSS-анимация

Чтобы запустить анимацию, достаточно создать @keyframes и указать его имя в animation. 

.box {
  animation: move 2s;
}

@keyframes move {
  from {
    transform: translateX(0);
  }

  to {
    transform: translateX(200px);
  }
}
Что происходит? Браузер берёт состояния из @keyframes и автоматически создаёт промежуточные кадры.

Несколько этапов анимации

Вместо from и to можно использовать проценты. 

@keyframes bounce {
  0% {
    transform: translateY(0);
  }

  50% {
    transform: translateY(-80px);
  }

  100% {
    transform: translateY(0);
  }
}
0% → 50% → 100%

Свойство animation

@keyframes описывает саму анимацию, а animation определяет, как её воспроизводить.

animation: move 2s ease-in-out infinite;
move
имя анимации
2s
длительность
ease-in-out
скорость
infinite
повторение
Одной строкой можно настроить всё воспроизведение анимации.

Имя и длительность анимации

Два параметра, которые нужны практически для любой анимации:

animation-name

Определяет, какую анимацию из @keyframes нужно запустить. 

animation-name: move;
animation-duration

Определяет, сколько времени занимает один цикл анимации. 

animation-duration: 2s;
.box {
  animation-name: move;
  animation-duration: 2s;
}

animation-timing-function

Определяет, с какой скоростью будет происходить анимация.

linear
Постоянная скорость
ease
Плавное начало и конец
ease-in
Медленно начинает
ease-out
Медленно заканчивает
ease-in-out
Медленно начинает и заканчивает
steps()
Движение отдельными шагами
.box {
  animation-timing-function: ease-in-out;
}

animation-delay

Позволяет сделать паузу перед началом анимации.

animation-delay: 1s;

→

Задержка может быть и отрицательной, например -0.5s — тогда анимация начнётся как будто она уже некоторое время выполняется.

animation-iteration-count

Определяет, сколько раз должна повториться анимация.

1
один раз
3
три раза
infinite
бесконечно

  animation-name: pulse;
  animation-duration: 1s;
  animation-iteration-count: infinite;
}
💡 Частый вариант: infinite используют для индикаторов загрузки, пульсации, вращения и других постоянно работающих эффектов.

animation-direction

Определяет, в каком направлении проигрывается анимация.

normal
Каждый цикл идёт от начала к концу. 
animation-direction:
  normal;
reverse
Каждый цикл идёт от конца к началу. 
animation-direction:
  reverse;
alternate
Направление чередуется. 
animation-direction:
  alternate;
→ normal ← reverse → ← → ← alternate 
.box {
  animation: move 1s infinite alternate;
}
💡 На практике часто используют alternate, чтобы элемент плавно двигался туда и обратно.

animation-play-state

Позволяет запускать и останавливать уже запущенную анимацию.

Попробуй поставить на паузу

Наведи курсор на синий квадрат
running
Анимация находится в состоянии воспроизведения.
paused
Анимация останавливается на текущем кадре.
Важный момент: элемент не возвращается в начало. Он продолжает движение с того места, где был поставлен на паузу. 
.box {
  animation: move 1.5s
    ease-in-out infinite alternate;
}

.box:hover {
  animation-play-state: paused;
}

@keyframes — сценарий анимации

Внутри @keyframes описываем, как элемент должен выглядеть в разные моменты анимации.

0%
→
50%
→
100% 
@keyframes example {
  0% {
    /* начальное состояние */
  }

  50% {
    /* промежуточное состояние */
  }

  100% {
    /* конечное состояние */
  }
}
Главная идея: мы задаём несколько важных моментов, а браузер сам создаёт переходы между ними.

Ключевые кадры: from и to

Для простой анимации достаточно указать начальное и конечное состояние.

from
начало
→
to
конец
@keyframes change {
  from {
    width: 65px;
    background: #4285c5;
  }

  to {
    width: 100px;
    background: #e44d7a;
  }
}
from = 0%
to = 100%
from и to — это просто более короткая запись для 0% и 100%.

Промежуточные состояния

Можно задать столько ключевых кадров, сколько нужно для сценария анимации.

@keyframes move {
  0% {
    transform: translateX(0);
    background: #4285c5;
  }

  50% {
    transform: translateX(120px);
    background: #8b5cf6;
  }

  100% {
    transform: translateX(0);
    background: #e44d7a;
  }
}
0% → 50% → 100%
Браузер сам рассчитывает изменения между ключевыми кадрами.

В одном кадре можно изменить несколько свойств

Ключевой кадр может одновременно задавать несколько CSS-свойств.

Анимация
@keyframes change {
  0% {
    width: 80px;
    height: 80px;
    background: #4285c5;
    border-radius: 10px;
  }

  100% {
    width: 160px;
    height: 50px;
    background: #e44d7a;
    border-radius: 25px;
  }
}
В результате браузер плавно изменяет размер, цвет и скругление одновременно.

Разбор: класс .show

Само объявление @keyframes ещё ничего не анимирует. Нужно применить анимацию к элементу.

Когда класс добавлен:
.notification-card.show
↓
запускается анимация
.notification-card.show {
  animation:
    notification-in
    0.6s
    ease-out
    forwards;
}
Важно: JavaScript не анимирует элемент напрямую — он только добавляет класс .show

Разбор: анимация тени

Здесь мы не двигаем сам текст — мы изменяем его text-shadow.

text-shadow
Задаём две цветные тени: розовую и голубую.
animation
Анимация длится 2 секунды и повторяется бесконечно.

  0%, 100% {
