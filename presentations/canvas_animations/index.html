Canvas Анимация

Создание движущейся графики с помощью HTML5 Canvas

Анимация в Canvas

Canvas управляется с помощью JavaScript, поэтому его содержимое можно изменять во время работы программы.

Для создания анимации мы изменяем свойства объекта и заново рисуем кадр.

  • изменяем координаты объекта;
  • очищаем предыдущий кадр;
  • рисуем объект заново;
  • повторяем процесс много раз в секунду.

Пример анимации


let x = 20;

function draw() {
  ctx.clearRect(
    0, 0,
    canvas.width,
    canvas.height
  );

  ctx.fillStyle = "#4285c5";
  ctx.fillRect(x, 110, 50, 50);

  x += 2;
}

setInterval(draw, 30);

Каждые 30 мс холст очищается и квадрат рисуется немного правее. Изменение координаты x создаёт движение.

Как работает анимация

Каждый кадр создаётся заново. Основной цикл состоит из нескольких шагов:

  1. Очистить холст — clearRect()
  2. Изменить координаты объекта
  3. Нарисовать объект в новом положении
  4. Повторить эти действия через небольшой интервал

let x = 0;

function animate() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  x += 2;
  ctx.fillRect(x, 100, 50, 50);
}

setInterval(animate, 30);

setInterval() запускает функцию через заданный промежуток времени. Здесь новый кадр создаётся каждые 30 мс.

Управление анимацией

Canvas рисует изображение только в момент выполнения JavaScript-кода. После этого нарисованный объект остаётся статичным.

Поэтому обычный цикл for не подходит для создания анимации: все итерации выполнятся слишком быстро.

Так делать нельзя!


for (let x = 0; x < 500; x += 2) {
  ctx.clearRect(0, 0, canvas.width, canvas.height);
  ctx.fillRect(x, 100, 50, 50);
}

Браузер не успеет показать каждый кадр — пользователь увидит только конечный результат.

Для анимации функцию отрисовки нужно запускать через определённые промежутки времени.

Способы запуска анимации

JavaScript предоставляет несколько способов повторно или отложенно запускать функции.

  • setInterval() — многократно вызывает функцию через заданный интервал.
  • setTimeout() — вызывает функцию один раз после указанной задержки.
  • requestAnimationFrame() — запускает функцию перед следующим обновлением экрана. 

// повторять каждые 30 мс
setInterval(draw, 30);

// выполнить один раз через 1 секунду
setTimeout(draw, 1000);

// запустить перед следующим кадром
requestAnimationFrame(draw);

Для современных Canvas-анимаций основным способом считается requestAnimationFrame().

Когда использовать разные методы?

setInterval()

Подходит для простых анимаций, которые должны постоянно повторяться через одинаковый промежуток времени. 


setInterval(draw, 30);

setTimeout()

Удобен, когда действие должно произойти один раз после определённой задержки. 


setTimeout(draw, 1000);

requestAnimationFrame()

Рекомендуется для плавных современных анимаций. Синхронизируется с обновлением экрана. 


requestAnimationFrame(draw);

addEventListener()

Используется, когда анимация должна реагировать на действия пользователя. 


canvas.addEventListener(
  "click", draw
);

requestAnimationFrame()

Просит браузер вызвать функцию перед следующей перерисовкой экрана.

  • используется для создания плавной анимации;
  • вызов происходит в подходящий момент перед отрисовкой кадра;
  • метод возвращает идентификатор запланированного вызова.

requestAnimationFrame(draw);

Частота кадров

Частота вызовов обычно соответствует частоте обновления экрана.

  • 60 Гц → примерно 60 кадров/с;
  • 120 Гц → примерно 120 кадров/с;
  • 144 Гц → примерно 144 кадров/с;
  • в фоновых вкладках вызовы обычно приостанавливаются.

Поэтому requestAnimationFrame() лучше подходит для анимации, чем фиксированный интервал.

Как работает цикл анимации?

requestAnimationFrame() планирует только один следующий вызов.


function draw() {
  // 1. обновляем состояние
  // 2. рисуем кадр

  requestAnimationFrame(draw);
}

requestAnimationFrame(draw);

После рисования функция снова планирует следующий кадр.

Схема:

requestAnimationFrame() → draw() → следующий кадр → draw() → …

Дополнительная информация

Время кадра — timestamp

Callback получает время, в которое браузер планирует отрисовать кадр. Его мы можем использовать для расчёта движения объектов. 


let start;

function draw(timestamp) {
  if (start === undefined) {
    start = timestamp;
  }

  const elapsed = timestamp - start;
  console.log(elapsed); // сколько миллисекунд прошло
  requestAnimationFrame(draw);
}

requestAnimationFrame(draw);

Пример: анимированная Солнечная система

В примере используются три изображения:

  • ☀️ Солнце — находится в центре;
  • 🌍 Земля — вращается вокруг Солнца;
  • 🌙 Луна — вращается вокруг Земли.

Изображения загружаются при запуске программы, после чего запускается цикл анимации.

Каждый новый кадр рассчитывает положение планет и заново рисует их на Canvas.

Как устроен цикл анимации

Каждый кадр строится заново по одному и тому же алгоритму.

  1. Очистить холст.
  2. Вычислить положение объектов.
  3. Нарисовать объекты.
  4. Запросить следующий кадр.

очистить → вычислить → нарисовать → следующий кадр

Сохраняем состояние Canvas (подробнее в лекции Canvas API)

При работе с трансформациями удобно временно изменять систему координат.

save() сохраняет состояние Canvas, а restore() возвращает его.


ctx.save();

ctx.translate(150, 150);
ctx.rotate(angle);

// рисуем объект

ctx.restore();

После restore() координаты возвращаются к состоянию, которое было до save().

Перемещаем начало координат

translate() переносит начало координат в указанную точку.


ctx.save();

ctx.translate(150, 150);

// (0, 0) теперь находится в центре Canvas
// рисуем Солнце в центре

ctx.restore();

Для Canvas размером 300 × 300 точка (150, 150) является центром.

Теперь можно задавать положение объектов относительно Солнца.

Поворачиваем систему координат

rotate() поворачивает систему координат на заданный угол.

Угол задаётся в радианах. Полный круг — 2π.


ctx.save();

ctx.rotate(earthAngle);
ctx.translate(150, 150);

// расстояние от Солнца
ctx.translate(105, 0);

// здесь будет Земля

ctx.restore();

При изменении earthAngle точка на расстоянии 105 перемещается по кругу.

Вычисляем угол Земли

Угол должен изменяться со временем.


const time = new Date();

const earthAngle =
  (2 * Math.PI / 60) * time.getSeconds() +
  (2 * Math.PI / 60000) * time.getMilliseconds();
  • getSeconds() — текущие секунды. Возвращает только целое число от 0 до 59
  • getMilliseconds() — текущие миллисекунды. Возвращает значение от 0 до 999

Полученный угол передаём в rotate():


ctx.rotate(earthAngle);

Рисуем Землю

Теперь объединяем все операции в одну последовательность.


ctx.save();

// 1. Центр Солнца
ctx.translate(150, 150);

// 2. Положение на орбите
ctx.rotate(earthAngle);
ctx.translate(105, 0);

// 3. Земля
ctx.drawImage(
  earth,
  -12, -12,
  24, 24
);

ctx.restore();

центр → поворот → расстояние → Земля

Добавляем Луну

Луна движется относительно уже найденного положения Земли.

Сначала вычислим её угол:


const moonAngle =
  (2 * Math.PI / 6) * time.getSeconds() +
  (2 * Math.PI / 6000) * time.getMilliseconds();

Затем добавим ещё один уровень трансформации:


ctx.save();

ctx.rotate(moonAngle);
ctx.translate(30, 0);

ctx.drawImage(moon, -5, -5, 10, 10);

ctx.restore();

Вложенный save() / restore() позволяет отдельно управлять движением Луны.

Рисуем орбиту

Орбиту Земли можно изобразить окружностью.


ctx.beginPath();

ctx.arc(
  150, 150,       // центр
  105,            // радиус
  0,
  Math.PI * 2     // полный круг
);

ctx.stroke();

Радиус 105 совпадает с расстоянием, на которое мы переносим Землю через translate(105, 0).

Собираем всё в draw()


function draw() {
  // 1. Очищаем предыдущий кадр
  ctx.clearRect(0, 0, 300, 300);

  // 2. Вычисляем углы
  const time = new Date();

  const earthAngle =
    (2 * Math.PI / 60) * time.getSeconds() +
    (2 * Math.PI / 60000) * time.getMilliseconds();

  const moonAngle =
    (2 * Math.PI / 6) * time.getSeconds() +
    (2 * Math.PI / 6000) * time.getMilliseconds();

  // 3. Центр Солнца
  ctx.save();
  ctx.translate(150, 150);

  // 4. Земля
  ctx.save();
  ctx.rotate(earthAngle);
  ctx.translate(105, 0);
  ctx.drawImage(earth, -12, -12, 24, 24);

  
}
  

// 5. Луна
  ctx.save();
  ctx.rotate(moonAngle);
  ctx.translate(30, 0);
  ctx.drawImage(moon, -5, -5, 10, 10);

  ctx.restore();
  ctx.restore();
  ctx.restore();

  // 6. Орбита
  ctx.beginPath();
  ctx.arc(150, 150, 105, 0, Math.PI * 2);
  ctx.stroke();

  // 7. Солнце
  ctx.drawImage(sun, 115, 115, 70, 70);

  // 8. Следующий кадр
  requestAnimationFrame(draw);

Запускаем анимацию

Осталось загрузить изображения и запустить draw().


const sun = new Image();
const earth = new Image();
const moon = new Image();

sun.src = "img/sun.png";
earth.src = "img/earth.png";
moon.src = "img/moon.png";

draw();

Первый вызов запускает draw(). В конце каждого кадра функция сама запрашивает следующий: 


requestAnimationFrame(draw);

draw() → следующий кадр → draw() → следующий кадр → …

Результат

Земля вращается вокруг Солнца, а Луна — вокруг Земли.

Пример: бесконечная панорама

Создадим эффект непрерывного движения фонового изображения.

  • панорама постепенно перемещается по холсту;
  • когда изображение подходит к краю, появляется его копия;
  • движение продолжается без видимого разрыва.

Такой приём часто используется в 2D-играх и анимации для создания движущегося фона.

Идея: одно изображение постоянно сменяется другим.

Основные параметры

Сначала задаём изображение и параметры его движения.


const img = new Image();

img.src = "hills.jpg";

const canvasXSize = 800;
const canvasYSize = 200;

const speed = 30;

const y = 0;
const dx = 0.75;
  • canvasXSize, canvasYSize — размеры холста;
  • y — вертикальное положение;
  • dx — изменение координаты x;
  • speed — интервал между кадрами.

Загрузка и подготовка изображения

После загрузки узнаём размеры изображения и подготавливаем Canvas.


let imgW;
let imgH;
let x = 0;

img.onload = () => {
  imgW = img.width;
  imgH = img.height;

  ctx = document.getElementById("canvas").getContext("2d");

  clearX = Math.max(imgW, canvasXSize);
  clearY = Math.max(imgH, canvasYSize);

  setInterval(draw, speed);
};
  • размер изображения учитывает scale;
  • x хранит его текущее положение;
  • после загрузки запускается draw().

Функция draw()

Каждый кадр выполняется одна и та же последовательность действий.

  1. Очистить область Canvas.
  2. Проверить положение изображения.
  3. При необходимости нарисовать его копию.
  4. Нарисовать основное изображение.
  5. Изменить координату x.

function draw() {
  ctx.clearRect(0, 0, clearX, clearY);

  // проверка положения
  // дополнительная копия

  ctx.drawImage(img, x, y, imgW, imgH);

  x += dx;
}

Как изображение движется?

Движение создаётся изменением координаты x.


ctx.drawImage(img, x, y, imgW, imgH);

x += dx;

Например, при dx = 0.75:


кадр 1:  x = 0
кадр 2:  x = 0.75
кадр 3:  x = 1.50
кадр 4:  x = 2.25
...

В результате изображение постепенно перемещается по холсту.

Зацикливание фона

Одного изображения недостаточно: после его выхода за границу появится пустое место. 


if (x > canvasXSize) {
  x = -imgW + x;
}

if (x > 0) {
  ctx.drawImage(img, -imgW + x, y, imgW, imgH);
}

Поэтому рядом с основным изображением заранее рисуется его копия.

Главный принцип: пока одна картинка уходит, другая уже занимает её место.

Почему нужны копии?

Копии позволяют избежать пустого пространства между изображениями.


┌──────────────────────────────────────┐
│      ┌──────────┐                    │
│      │ ПАНОРАМА │   ← основная       │
│      └──────────┘                    │
│                  ┌──────────┐        │
│                  │ ПАНОРАМА │ ← копия│
│                  └──────────┘        │
└──────────────────────────────────────┘
                     ← движение
  • изображения имеют одинаковые размеры;
  • они располагаются вплотную друг к другу;
  • при движении одна копия сменяет другую.

Такой приём называют зацикливанием фона (looping background).

Соберем все вместе


    // 1.Изображение панорамы

    const img = new Image();

    img.src = './img/hills.jpg';

    // 2.Размер Canvas
    const canvasXSize = 800;
    const canvasYSize = 400;

    // 3.Скорость обновления
    const speed = 30;

    // 4.Вертикальное положение
    const y = 0;

    // 5.Скорость движения
    const dx = 0.75;

    // 6.Переменные изображения
    let imgW;
    let imgH;


    // 7.Текущая координата X
    let x = 0;

    // 8.Контекст Canvas
    let ctx;

    // После загрузки изображения

    img.onload = () => {
        // 9.Вычисляем размеры изображения
        imgW = img.width;
        imgH = img.height;

        // 10.Получаем Canvas
        const canvas = document
        .getElementById('panoramaCanvas');

        ctx = canvas.getContext('2d');

        // 11.Запускаем анимацию
        setInterval(draw, speed);
    };

Соберем все вместе


            // Функция рисования одного кадра
            function draw() {
              // 12.Очищаем Canvas
              ctx.clearRect(0, 0, canvasXSize, canvasYSize);

              // 13.Основное изображение

              ctx.drawImage(img, Math.round(x), y, imgW, imgH);

              // 14.Копия изображения

              ctx.drawImage(img, Math.round(x + imgW), y, imgW, imgH);

              // 15.Если основное изображение полностью ушло влево

              if (x <= -imgW) {
                x = 0;
              }

              // 16.Двигаем изображение
              x -= dx;
            }

Результат: бесконечная панорама

Две одинаковые копии изображения движутся вместе, поэтому одна постоянно заменяет другую.

Алгоритм бесконечной панорамы

  1. Загрузить изображение.
  2. Вычислить его размеры.
  3. Запустить цикл draw().
  4. Очистить Canvas.
  5. Нарисовать изображение и его копию.
  6. Изменить x.
  7. При достижении края вернуть изображение в начало.

Ключевая идея: мы не перемещаем картинку физически — каждый кадр заново рисуем её в новой координате.

Оптимизация Canvas

Простые сцены Canvas обрабатывает быстро, но в сложных анимациях каждый кадр может требовать множества вычислений.

Способы оптимизации:

  • уменьшаем количество перерисовок
  • избегаем лишних вычислений
  • повторно используем готовые данные
  • перерисовываем только то, что действительно изменилось

Цель: уменьшить работу браузера при каждом кадре.

Предварительная отрисовка (Offscreen Canvas)

Если один и тот же объект приходится рисовать в каждом кадре, его можно заранее нарисовать на невидимом (offscreen) canvas.

Во время анимации вместо повторного рисования объекта достаточно скопировать уже готовое изображение.

Пример: 

const offscreen = document.createElement('canvas');

offscreen.width = 100;
offscreen.height = 100;

const offCtx = offscreen.getContext('2d');

// Рисуем объект один раз
offCtx.fillStyle = 'orange';
offCtx.beginPath();
offCtx.arc(50, 50, 40, 0, 2 * Math.PI);
offCtx.fill();


// В каждом кадре только копируем
function draw() {
  ctx.clearRect(0, 0, canvas.width, canvas.height);

  ctx.drawImage(offscreen, x, y);

  requestAnimationFrame(draw);
}

Используйте целые координаты

Для изображений лучше использовать целые координаты:

ctx.drawImage(img, 100, 50);

Вместо дробных:

ctx.drawImage(img, 100.3, 50.7);

Целые координаты позволяют избежать лишних вычислений при сглаживании изображения.

При необходимости координаты можно округлить:

ctx.drawImage(
  img,
  Math.floor(x),
  Math.floor(y)
);

Идея: если точность до дробных пикселей не нужна, используйте целые координаты.

Не масштабируйте изображения каждый кадр

Метод drawImage() позволяет изменять размер изображения во время рисования, но постоянное масштабирование требует дополнительных вычислений.

Если изображение часто используется в одном и том же размере, лучше заранее подготовить его масштабированную копию (offscreen canvas).

Используйте CSS для статичного фона

Если фон не меняется во время анимации, его не обязательно рисовать на Canvas. Можно разместить фоновое изображение в обычном HTML-элементе с помощью CSS, а Canvas расположить поверх него.

Пример: 

<div class="scene">
  <canvas id="canvas"></canvas>
</div>
.scene {
  width: 800px;
  height: 400px;
  background: url('./img/background.jpg') center / cover;
}

canvas {
  display: block;
}

Теперь Canvas отвечает только за анимацию, а статичный фон находится в отдельном HTML-элементе.

Видео на Canvas

Canvas может использовать HTML-элемент <video> как источник изображения.

Каждый кадр видео можно получить и нарисовать на Canvas с помощью drawImage().

ctx.drawImage(video, 0, 0);

В результате содержимое видео становится частью изображения Canvas.

Зачем размещать видео на Canvas?

Обычный <video> уже умеет показывать видео. Canvas нужен, когда видео необходимо обрабатывать.

  • накладывать графику и эффекты
  • изменять цвета и пиксели видео
  • обрезать или масштабировать изображение
  • объединять видео с другими объектами Canvas
  • создавать собственные визуальные эффекты

Идея: видео становится обычным источником изображения для Canvas.

Пример: видео на Canvas

Сначала создаём видео и Canvas:

<video id="video" src="./video.mp4"></video>
<canvas id="canvas" width="640" height="360"></canvas>

Браузерные 2D-игры на Canvas

Canvas позволяет создавать простые 2D-игры прямо в браузере.

В игре Canvas обычно используется для:

  • отрисовки игрового мира
  • персонажей и объектов
  • анимации
  • обработки действий игрока
  • проверки столкновений
  • создания визуальных эффектов

Рассмотрим небольшую игру «Найди кота».

Игрок должен найти кота в комнате с помощью виртуального фонарика.

Идея: игра постоянно хранит состояние, обновляет его и рисует новый кадр.

Из чего состоит игра?

Даже небольшая игра состоит из нескольких основных частей.

// Canvas - игровое поле
const canvas = document.getElementById('game');
const ctx = canvas.getContext('2d');

// Игровые объекты
const room = new Image();
const cat = new Image();

// Состояние игры
const mouse = {
  x: canvas.width / 2,
  y: canvas.height / 2
};

const catData = {
  x: 100,
  y: 100,
  width: 150,
  height: 150
};

Важно: Canvas сам по себе не хранит понятие «кот», «игрок» или «игра». Мы описываем всё это самостоятельно в JavaScript.

Игровое состояние

Чтобы управлять игрой, нам нужно хранить её текущее состояние.

Например, положение кота:

const catData = {
  x: Math.random() * (canvas.width - 150),
  y: Math.random() * (canvas.height - 150),
  width: 150,
  height: 150
};

Здесь объект содержит всё необходимое для его отображения:

  • x — координата по горизонтали
  • y — координата по вертикали
  • width — ширина
  • height — высота

Игровое состояние — это данные, которые описывают происходящее в игре в данный момент.

Случайное размещение кота

При запуске игры кот появляется в случайном месте комнаты.

catData.x =
  Math.random() * (canvas.width - catData.width);

catData.y =
  Math.random() * (canvas.height - catData.height);

Math.random() возвращает число от 0 до 1.

Поэтому координата умножается на доступный диапазон.

Math.random() * (1000 - 80)

Кот никогда не окажется за правой или нижней границей Canvas, потому что из размера поля мы заранее вычитаем размер кота.

После нахождения кота можно повторить эту операцию, чтобы спрятать его в новом месте.

Получаем положение мыши

Для эффекта фонарика нам нужно знать, где находится курсор внутри Canvas.

const mouse = {
  x: canvas.width / 2,
  y: canvas.height / 2
};

canvas.addEventListener('mousemove', (e) => {
  const rect = canvas.getBoundingClientRect();

  mouse.x = e.clientX - rect.left;
  mouse.y = e.clientY - rect.top;
});

clientX и clientY относятся к окну браузера, поэтому сначала нужно получить положение Canvas.

rect.left и rect.top позволяют перевести координаты мыши в систему координат Canvas.

Результат: mouse.x и mouse.y всегда показывают, где находится курсор на игровом поле.

Проверка попадания

При клике нужно определить, находится ли курсор достаточно близко к центру кота.

const dx = mouse.x - (catData.x + catData.width / 2);

const dy = mouse.y - (catData.y + catData.height / 2);

const distance = Math.sqrt(dx * dx + dy * dy);

if (distance < 60) {
  alert('Ты нашел кота 😺');
}

Здесь используется расстояние между двумя точками.

Теорема Пифагора: 

distance = √(dx² + dy²)

Если расстояние меньше 60 пикселей, считаем, что игрок попал по коту.

Это простой пример проверки столкновения.

Рендеринг игрового мира

Каждый кадр Canvas очищается и рисуется заново.

function render() {
  ctx.clearRect(0,0,canvas.width,canvas.height);

  // Комната
  ctx.drawImage(room,0,0,canvas.width,canvas.height);

  // Кот
  ctx.drawImage(cat,catData.x,catData.y,catData.width,catData.height);

  requestAnimationFrame(render);
}

Порядок рисования имеет значение.

  1. очищаем Canvas
  2. рисуем комнату
  3. рисуем кота
  4. рисуем эффекты

Последний нарисованный объект находится поверх предыдущих.

Создаём эффект фонарика

После комнаты и кота поверх всего изображения создаётся тёмный слой.

const gradient =
  ctx.createRadialGradient(mouse.x,mouse.y,20,mouse.x,mouse.y,60);

gradient.addColorStop(0,'rgba(0,0,0,0)');

gradient.addColorStop(1,'rgba(0,0,0,0.95)');

ctx.fillStyle = gradient;

ctx.fillRect(0,0,canvas.width,canvas.height);

В центре градиента прозрачность максимальная, поэтому изображение хорошо видно.

К краям градиент становится почти чёрным.

Так обычный радиальный градиент превращается в фонарик.

Повторяем

Параллельно браузер обрабатывает действия игрока:

  • mousemove → перемещаем фонарик
  • click → проверяем, найден ли кот

Если кот найден — его координаты меняются, и игра продолжается с новым местом расположения.

В этой игре необходимо угадать загаданное слово, называя буквы. За каждую ошибку постепенно рисуется виселица.

Как работает игра

Игрок вводит букву.

Если буква есть в слове — она открывается. Если буквы нет — увеличивается количество ошибок.

После каждой попытки обновляется состояние игры и перерисовывается Canvas.

Что хранит игра

Для работы игры необходимо хранить несколько значений:

  • загаданное слово;
  • открытые буквы;
  • количество ошибок;
  • максимальное количество ошибок.

Загаданное слово

Слово можно хранить в переменной. Например:


const word = "JAVASCRIPT";

Отдельно храним буквы, которые уже были угаданы.

Проверка буквы

Когда игрок вводит букву, программа проверяет, содержится ли она в загаданном слове. 


if (word.includes(letter)) {
  // Буква есть в слове
} else {
  // Ошибка
}

Canvas

В нашей игре Canvas будет использоваться для рисования виселицы и постепенного добавления частей тела.

Получаем Canvas


const canvas = document.querySelector("#game");

const ctx = canvas.getContext("2d");

Переменная ctx содержит контекст рисования, через который мы будем создавать линии и фигуры.

Количество ошибок

Каждая ошибка увеличивает значение переменной errors.


errors++;

if (errors === 1) {
  // Рисуем основу
}

В зависимости от количества ошибок добавляется новая часть виселицы.

Функция draw()

Чтобы не повторять код рисования, создадим отдельную функцию draw().


function draw() {
  // Очистка Canvas
  // Рисование виселицы
  // Рисование частей тела
}

Очистка Canvas


ctx.clearRect(
  0,
  0,
  canvas.width,
  canvas.height
);

Этот метод очищает Canvas перед новой отрисовкой. Благодаря этому изображение всегда соответствует текущему состоянию игры.

Обновление игры

После каждой попытки игрока необходимо:

  1. проверить букву;
  2. изменить состояние игры;
  3. очистить Canvas;
  4. перерисовать виселицу.

Игровой цикл

Игра постоянно проходит через последовательность действий:

Событие → изменение состояния → отрисовка → результат

В игре «Виселица» событием является ввод буквы, а результатом — открытая буква или новая часть виселицы.

Проверка победы

Если все буквы слова открыты, игрок побеждает.


if (guessedWord === word) {
  // Победа
}

Проверка поражения

Если количество ошибок достигло максимального значения, игра заканчивается поражением. 


if (errors >= maxErrors) {
  // Поражение
}

Рисуем график на Canvas

Canvas можно использовать не только для рисунков, но и для отображения данных.

Например, построим столбчатый график продаж за несколько месяцев.


const data = [30, 50, 40, 70, 60];

Каждое число определяет высоту своего столбца.

Как нарисовать столбец?

Для столбца используем прямоугольник.


ctx.fillRect(
  x,
  500 - value (точка от которой счтаем высоту столбца),
  50,
  value (высота столбца)
);

Значение показателя определяет высоту столбца.

Чем больше value — тем выше столбец.

Рисуем все данные

Проходим по массиву данных циклом. Для каждого значения создаём свой столбец.


data.forEach((value, index) => {

  const x = 50 + index * 80;

  ctx.fillRect(
    x,
    500 - value,
    50,
    value
  );

});

const x = 50 + index * 80; — определяет горизонтальное положение столбца, 50 — отступ слева, 80 — расстояние между столбцами.

Функция drawChart()

Вынесем построение графика в отдельную функцию.


function drawChart() {

  ctx.clearRect(0, 0, canvas.width, canvas.height);

  data.forEach((value, index) => {

    const x = 50 + index * 80;

    ctx.fillRect(
      x,
      500 - value,
      50,
      value
    );

  });
}

Перед каждой новой отрисовкой Canvas очищается.

Изменяем данные

Если изменить значение в массиве, график можно построить заново. Для этого нужно слушать события изменения ползунков.


data[0] = 80;

drawChart();

Было значение 30 — стало 80.

Canvas очищается и рисует новый график.

Строим график

Данные хранятся в массиве. Для каждого значения рисуем свой столбец.


const data = [100, 200, 150, 300, 250];

const canvas =
  document.querySelector("#chartCanvas");

const ctx =
  canvas.getContext("2d");


function drawChart() {

  // Очищаем Canvas
  ctx.clearRect(
    0,
    0,
    canvas.width,
    canvas.height
  );
  ...
  

...
  // Рисуем оси
  ctx.beginPath();

  ctx.moveTo(50, 450);
  ctx.lineTo(550, 450);

  ctx.moveTo(50, 450);
  ctx.lineTo(50, 50);

  ctx.stroke();


  // Рисуем столбцы
  data.forEach((value, index) => {

    const x = 70 + index * 90;
    const y = 450 - value;

    ctx.fillRect(x, y, 50, value);
  });
}

drawChart();

Слушаем изменения ползунков

Каждый ползунок изменяет своё значение в массиве data.


const inputs =
  document.querySelectorAll(".chart-input");

inputs.forEach((input, index) => {
  input.addEventListener("input", () => {
    // Меняем значение в массиве
    data[index] = Number(input.value);
    // Строим график заново
    drawChart();
  });
});

index связывает ползунок с соответствующим элементом массива:
