Введение

IntersectionObserver позволяет отслеживать, когда элемент появляется в области просмотра.

Это удобно для интерфейсов, которые должны реагировать на прокрутку страницы.

Например, мы можем автоматически определять, какой раздел статьи сейчас читает пользователь.

API

IntersectionObserver создаётся с помощью конструктора.

В callback браузер передаёт информацию об элементах, состояние пересечения которых изменилось.

Нам не нужно постоянно проверять положение элемента через scroll.

Примеры

Один из распространённых паттернов — Scroll Spy.

Пользователь прокручивает страницу, а навигация автоматически подсвечивает текущий раздел.

Такой интерфейс часто встречается в документации и технических статьях.

Итоги

IntersectionObserver позволяет связать состояние страницы с viewport.

Мы наблюдаем за секциями статьи и на основании этого изменяем состояние навигации.

Получается простой Scroll Spy.
