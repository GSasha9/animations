HTML5 Canvas

Рисование и работа с графикой в JavaScript

Элемент <canvas>

<canvas> — специальная область на веб-странице, предназначенная для рисования с помощью JavaScript.

Внешне он похож на <img>, однако между ними есть важное различие:

  • <img> отображает готовое изображение из файла через атрибут src
  • <canvas> изначально пуст. всё содержимое создаётся программно через Canvas API

У элемента <canvas> есть два собственных атрибута:

  • width — ширина области рисования
  • height — высота области рисования

Если размеры не указать, браузер создаст холст размером 300 × 150 пикселей. 


<canvas width="600" height="400"></canvas>

Для удобного обращения из JavaScript рекомендуется добавить обычный HTML-атрибут id. 


<canvas id="myCanvas" width="600" height="400">
</canvas>

Размер холста можно изменить не только через атрибуты width и height, но и с помощью CSS.

Однако важно понимать разницу между этими способами.

Атрибуты width и height задают реальный размер области рисования. 

 <canvas width="600" height="400"></canvas>

Если изменить размеры только через CSS, изменится лишь отображение элемента на странице, а внутреннее разрешение холста останется прежним.

Рассмотрим разницу между изменением размера холста и его размером на странице.

Размер задан через HTML

Внутренний размер: 300 × 150 px

Размер изменён через CSS

Внутренний размер: 300 × 150 px
Размер на странице: 600 × 300 px

Изменение размера Canvas только через CSS может привести к ухудшению качества изображения.

Рисунок может стать размытым или искажённым, поскольку внутренний размер области рисования не изменяется.

Поэтому для Canvas рекомендуется задавать размеры именно через HTML-атрибуты, а CSS использовать для внешнего оформления. 

 <canvas width="600" height="400"></canvas>

Как и любой другой HTML-элемент, <canvas> можно оформлять с помощью CSS.

Например, можно добавить рамку, фон, внешние отступы и другие стили:

 canvas { border: 2px solid #333; background: #f5f5f5; margin: 20px; }

Доступность (Accessibility)

Элемент <canvas>, как и <img> или <video>, должен оставаться доступным для всех пользователей.

Содержимое Canvas создаётся с помощью JavaScript, поэтому его не могут напрямую «увидеть» некоторые вспомогательные инструменты, например screen readers и поисковые роботы.

Чтобы сделать Canvas доступнее, рекомендуется добавлять альтернативное содержимое внутрь элемента.

Оно используется, если браузер не поддерживает Canvas или пользователь не может получить доступ к содержимому холста.

В качестве альтернативного содержимого можно использовать текстовое описание: 


<canvas id="stockGraph" width="150" height="150">
  Текущая стоимость акции: 3.15 $
</canvas>

Или добавить статичное изображение:


<canvas id="clock" width="150" height="150">
  <img src="clock.png" alt="Изображение часов">
</canvas>

Такой подход делает страницу более доступной и соответствует современным требованиям веб-разработки.

В реальном проекте альтернативное содержимое может выглядеть так:

Что видит обычный пользователь:

Текущая стоимость акции: 3.15 $

Альтернативное содержимое:

Текущая стоимость акции: 3.15 $

Этот текст находится внутри Canvas и может быть использован как альтернатива. 


<canvas id="stockCanvas" width="300" height="180">
  Текущая стоимость акции: 3.15 $
</canvas>

Canvas отображает график, а текст внутри него содержит описание информации, которую представляет график.

В отличие от элемента <img>, элемент <canvas> обязательно должен иметь закрывающий тег. 


<canvas id="myCanvas"></canvas>

Всё содержимое между <canvas> и </canvas> считается резервным (fallback) содержимым. 


<canvas id="stockGraph">
  Текущая стоимость акции: 3.15 $
</canvas>

Если закрывающий тег отсутствует, браузер может воспринять последующий HTML-код страницы как содержимое Canvas.

Это приведёт к ошибкам отображения страницы.

Если Canvas используется только как декоративный элемент и не содержит важной информации, резервное содержимое добавлять не обязательно. 


<canvas
  id="background"
  role="presentation">
</canvas>

Атрибут role="presentation" сообщает вспомогательным технологиям, что элемент используется исключительно для оформления страницы.

Контекст рисования (Rendering Context)

Сам элемент <canvas> — это только область для рисования.

Сам по себе Canvas не содержит инструментов для создания графики. Чтобы начать рисовать, необходимо получить контекст рисования (rendering context).

Контекст — это объект, который предоставляет методы для работы с графикой:

  • рисования линий
  • создания фигур
  • добавления текста
  • работa с изображениями и др.
<canvas>
область для рисования
→
Контекст
инструменты рисования

Canvas поддерживает несколько типов контекста. В этом курсе мы будем использовать двумерный контекст (2d).

Чтобы получить 2D-контекст, сначала получаем сам Canvas, а затем вызываем метод getContext(): 


const canvas = document.getElementById("myCanvas");

const ctx = canvas.getContext("2d");

Теперь переменная ctx содержит контекст, через который мы сможем рисовать на Canvas. 


ctx.fillRect(50, 30, 150, 100);

Получение контекста

Работа с Canvas всегда начинается с двух шагов:

  1. Получить элемент <canvas> из HTML-документа.
  2. Получить его контекст рисования.

const canvas = document.getElementById("canvas");

const ctx = canvas.getContext("2d");

В первой строке JavaScript находит Canvas по его id с помощью метода document.getElementById().

Во второй строке вызывается getContext("2d"). Он возвращает объект CanvasRenderingContext2D.

Именно через этот объект выполняются все операции рисования.

После получения контекста практически весь код рисования будет использовать переменную ctx. 


ctx.fillRect(20, 20, 100, 50);
ctx.beginPath();
ctx.arc(
  100,
  100,
  40,
  0,
  Math.PI * 2
);

Например, с помощью ctx можно создавать прямоугольники, линии, окружности и другие элементы.

Важно: без получения контекста Canvas остаётся пустой областью, и рисовать на нём невозможно.

Координатная система Canvas

Прежде чем рисовать, важно понять, как устроена система координат Canvas.

Каждый холст представляет собой сетку, в которой 1 единица соответствует 1 пикселю.

Начало координат находится в левом верхнем углу и имеет координаты (0, 0).

(0, 0) X → Y ↓
  • Ось X направлена вправо.
  • Ось Y направлена вниз.

Любой объект размещается относительно начала координат (0, 0).

Например, если фигура начинается в координатах (50, 30), это означает:

  • 50 пикселей от левого края;
  • 30 пикселей от верхнего края.
(0, 0)
(50, 30)

Позже мы рассмотрим, как изменять систему координат: переносить начало координат, поворачивать и масштабировать холст.

Пока будем использовать стандартную систему координат.

Первые фигуры: прямоугольники

Canvas не содержит готовых фигур, как SVG. Основными графическими примитивами являются прямоугольники и контуры (paths).

Более сложные объекты — окружности, звёзды, многоугольники и другие фигуры — создаются на основе контуров.

Для работы с прямоугольниками Canvas предоставляет три основных метода: 


ctx.fillRect(x, y, width, height);
ctx.strokeRect(x, y, width, height);
ctx.clearRect(x, y, width, height);
  • fillRect() — рисует закрашенный прямоугольник.
  • strokeRect() — рисует только контур.
  • clearRect() — очищает указанную область.

Параметры прямоугольника

Все три метода используют одинаковые четыре параметра:


ctx.fillRect(x, y, width, height);
  • x — координата левого верхнего угла по оси X;
  • y — координата левого верхнего угла по оси Y;
  • width — ширина прямоугольника;
  • height — высота прямоугольника.
(x, y) width height

Именно с этих методов обычно начинается знакомство с Canvas API: они позволяют быстро понять принцип работы координат и размеров объектов.

Пример работы с прямоугольниками

Используем все три метода для последовательного изменения Canvas:


const canvas = document.getElementById("rectExample");
const ctx = canvas.getContext("2d");

ctx.fillRect(25, 25, 100, 100);

ctx.clearRect(45, 45, 60, 60);

ctx.strokeRect(50, 50, 50, 50);
1. fillRect()

Рисует чёрный квадрат 100 × 100 px.

2. clearRect()

Очищает центральную область 60 × 60 px.

3. strokeRect()

Рисует внутри области прямоугольник с контуром.

Прямоугольники рисуются сразу

Методы fillRect(), strokeRect() и clearRect() сразу выполняют операцию на Canvas.

В отличие от контуров (Path), их не нужно дополнительно завершать или отображать специальным методом.

Поэтому прямоугольники — один из самых простых способов познакомиться с Canvas API и понять, как координаты определяют положение объекта на холсте.

Контуры (Paths)

Помимо прямоугольников, Canvas позволяет создавать практически любые фигуры с помощью контуров (paths).

Контур — это набор соединённых элементов: точек, линий, дуг и кривых.

С помощью контуров можно создавать многоугольники, окружности, кривые Безье, сложные фигуры и другие изображения.

Основные методы работы с контуром

Для создания и отображения контуров используются несколько основных методов.

ctx.beginPath();

Создаёт новый контур. Обычно именно с этого метода начинается рисование каждой новой фигуры.

ctx.closePath();

Замыкает контур, соединяя последнюю точку с первой прямой линией.

ctx.stroke();

Рисует только контур фигуры.

ctx.fill();

Заполняет внутреннюю область фигуры выбранным цветом.

Последовательность работы:
beginPath() → построение → stroke() / fill()

Важное отличие fill() и stroke()

ctx.fill();

Заполняет внутреннюю область фигуры.

closePath()
можно не вызывать
ctx.stroke();

Рисует только линии контура.

closePath()
нужен для замыкания

Важно:

Метод fill() автоматически замыкает контур перед заливкой, поэтому вызывать closePath() необязательно.

Метод stroke() этого не делает, поэтому при рисовании замкнутой фигуры closePath() часто приходится вызывать самостоятельно.

Метод moveTo() — перемещение пера

При построении контуров часто возникает необходимость перейти в новую точку, не рисуя линию.

Для этого используется метод moveTo().

Метод lineTo() — рисование линий

После того как начальная точка задана с помощью moveTo(), можно рисовать линии методом lineTo(). 

ctx.lineTo(x, y);

Метод проводит прямую линию от текущей точки к указанным координатам (x, y).

Важно: lineTo() только добавляет линию в контур. Сам контур пока не отображается.

Пример: закрашенный и контурный треугольник

Рассмотрим два способа отображения одного и того же контура.

Закрашенный треугольник

ctx.beginPath();
ctx.moveTo(25, 25);
ctx.lineTo(105, 25);
ctx.lineTo(25, 105);
ctx.fill();

fill() автоматически замыкает контур перед заливкой.

Контурный треугольник

ctx.beginPath();
ctx.moveTo(125, 125);
ctx.lineTo(125, 45);
ctx.lineTo(45, 125);
ctx.closePath();
ctx.stroke();

stroke() не замыкает контур автоматически.

Рисование дуг и окружностей

Для создания окружностей, дуг и округлых элементов в Canvas используются методы arc() и arcTo().

На практике чаще всего применяется именно arc(), так как он позволяет рисовать как полные окружности, так и отдельные дуги. 

ctx.arc(x,y,radius,startAngle,endAngle,counterclockwise);

Параметры:

  • x, y — координаты центра окружности
  • radius — радиус
  • startAngle — угол начала дуги
  • endAngle — угол окончания дуги
  • counterclockwise — направление рисования
Перед использованием arc(), как и при рисовании линий, необходимо создать новый контур с помощью beginPath(). 
const canvas = document.getElementById("myCanvas");
const ctx = canvas.getContext("2d");

ctx.beginPath();

ctx.arc(100, 75, 50, 0, Math.PI * 2);

ctx.stroke();

Углы в Canvas и радианы

Особенность метода arc() заключается в том, что углы задаются не в градусах, а в радианах.

Для перевода градусов в радианы используется формула:

const radians = (Math.PI / 180) * degrees;

0

начало окружности

Math.PI

180° — половина окружности

Math.PI * 2

360° — полная окружность

Пример рисования окружности

ctx.beginPath();

ctx.arc(
  100, 100,
  50,
  0, Math.PI * 2
);

ctx.stroke();

В этом примере создаётся окружность с центром в точке (100, 100) и радиусом 50 пикселей.

Важно: изменяя значения startAngle и endAngle, можно рисовать не только окружности, но и дуги любой длины.

Дуги используются, например, для круговых диаграмм, индикаторов загрузки и циферблатов часов.

Практическое задание: «Домик»

Нарисуйте простой домик на Canvas, используя изученные методы.

Что должно быть на рисунке?

  • 🏠 стены дома — прямоугольник
  • 🔺 крыша — треугольник
  • 🚪 дверь — прямоугольник
  • ⭕ окно — окружность

Обязательно используйте

  • fillRect() — для стен и двери
  • arc() — для круглого окна
  • moveTo() — начало крыши
  • lineTo() — стороны крыши
Задача: самостоятельно выбрать координаты и размеры всех элементов.

Не используйте изображения или SVG. Домик должен быть полностью нарисован средствами Canvas API.

Подсказки

1. Стены дома 

ctx.fillRect(
  150, 180, 250, 150
);

Укажите координаты левого верхнего угла, затем ширину и высоту.

2. Крыша

ctx.beginPath();
ctx.moveTo(130, 180);
ctx.lineTo(275, 70);
ctx.lineTo(420, 180);
ctx.closePath();
ctx.fill();

Три точки образуют треугольник.

3. Дверь

ctx.fillRect(
  245, 240, 60, 90
);

Дверь — обычный прямоугольник внутри стен дома.

4. Круглое окно 

ctx.beginPath();
ctx.arc(210, 230, 30,0, Math.PI * 2);
ctx.fill();

Первые два значения — центр, третье — радиус.

Как оформить код?

Перед рисованием нужно получить Canvas и его контекст.

1. Находим Canvas

 const canvas = document.querySelector('#canvas');

2. Получаем контекст

 const ctx = canvas.getContext('2d');
Теперь через ctx можно рисовать на Canvas.

Отдельная функция для каждого элемента

Чтобы код было легче читать, каждый элемент можно вынести в отдельную функцию.

function drawHouse() {
  // стены
}
function drawRoof() {
  // крыша
}
function drawDoor() {
  // дверь
}
function drawWindow() {
  // окно
}
Одна функция — один элемент рисунка.

Вызываем функции

После создания функций нужно их вызвать.

drawHouse();
drawRoof();
drawDoor();
drawWindow();

Порядок работы

Canvas → контекст → функции → вызов функций

Кривые Безье

Для рисования плавных линий используются кривые Безье (Bézier curves), которые применяются в компьютерной графике, анимации и векторных редакторах.

Квадратичная кривая

ctx.quadraticCurveTo(
  cp1x, cp1y,
  x, y
);

Использует одну управляющую точку.

Кубическая кривая

ctx.bezierCurveTo(
  cp1x, cp1y,
  cp2x, cp2y,
  x, y
);

Использует две управляющие точки.

Важно:

Обе функции начинают построение кривой от текущей позиции пера и заканчивают её в точке (x, y).

Квадратичная и кубическая кривые

Главное различие между двумя типами кривых — количество управляющих точек, которые определяют форму линии.

Квадратичная

  • начальная точка
  • конечная точка
  • 1 управляющая точка — задаёт изгиб

Кубическая

  • начальная точка
  • конечная точка
  • 2 управляющие точки — позволяют создавать более сложные формы
Важно:

В Canvas управляющие точки не отображаются на экране. Поэтому форму кривой приходится подбирать экспериментально, изменяя координаты вручную.

Минимальный пример кривой Безье

Код

ctx.beginPath();

ctx.moveTo(50, 150);

ctx.quadraticCurveTo(
  150, 30,
  250, 150
);

ctx.stroke();

Кривая начинается в точке (50, 150) и заканчивается в точке (250, 150).

Метод rect()

Ранее мы познакомились с методами fillRect() и strokeRect(), которые сразу рисуют прямоугольник на холсте.

Метод rect() работает иначе — он не рисует фигуру, а только добавляет прямоугольник в текущий контур. 

ctx.rect(x, y, width, height);

Параметры:

  • x, y — координаты левого верхнего угла
  • width — ширина прямоугольника
  • height — высота прямоугольника

После создания контура его необходимо отобразить с помощью stroke() или fill(). 

ctx.beginPath();

ctx.rect(20, 20, 100, 60);

ctx.stroke();
Важно: перед rect() обычно не требуется дополнительно вызывать moveTo(). Метод сам устанавливает начальную точку в координаты (x, y).

Что важно запомнить?

fillRect() / strokeRect()

  • сразу рисуют прямоугольник
  • не требуют beginPath()
  • не требуют отдельного fill() или stroke()

rect()

  • только создаёт контур
  • используется внутри текущего пути
  • после rect() нужен stroke() или fill()
Когда использовать rect()?

Когда прямоугольник является частью более сложной фигуры, состоящей из нескольких контуров.

Когда нужен rect()?

rect() удобно использовать, когда нужно добавить прямоугольник в общий контур вместе с другими фигурами.

Код

ctx.beginPath();

// Прямоугольник
ctx.rect(40, 50, 220, 120);
// Переходим к началу окружности
ctx4.moveTo(180, 135);
// Круг
ctx.arc(150, 135, 30, 0, Math.PI * 2);
// Рисуем весь контур
ctx.stroke();

И прямоугольник, и круг добавляются в один контур.

Результат

Фигуры с отверстиями

В Canvas можно рисовать не только сплошные фигуры, но и фигуры с отверстиями. Для этого внешний и внутренний контуры должны быть нарисованы в противоположных направлениях.

Направление обхода

  • внешний контур — по часовой стрелке
  • внутренний контур — против часовой стрелки

Можно сделать и наоборот — главное, чтобы направления отличались.

Что делает fill()?

Canvas анализирует направление обхода контуров.

Контур, нарисованный в противоположном направлении, воспринимается как отверстие и не закрашивается.

Главное правило: внешний и внутренний контуры должны иметь разное направление обхода.

Пример фигуры с отверстием

ctx.beginPath();

// Внешний треугольник
ctx.moveTo(0, 0);
ctx.lineTo(150, 0);
ctx.lineTo(75, 130);

// Внутренний треугольник
ctx.moveTo(75, 20);
ctx.lineTo(50, 60);
ctx.lineTo(100, 60);

ctx.fill();

Внешний контур идёт по часовой стрелке, а внутренний — против часовой.

Результат

Важно: если оба контура нарисовать в одном направлении, внутренний контур не станет отверстием.

Цвета (Colors)

Чтобы добавлять цвет фигурам, в Canvas используются два основных свойства:

fillStyle

Задаёт цвет или стиль заливки фигуры.

ctx.fillStyle = color;

strokeStyle

Задаёт цвет или стиль контура фигуры.

ctx.strokeStyle = color;
Параметр color может быть CSS-цветом, градиентом или текстурным паттерном. Градиенты и паттерны рассмотрим позже.
По умолчанию:
  • цвет заливки — #000000 (чёрный);
  • цвет контура — #000000 (чёрный).

Изменение цвета фигур

После того как мы задаём значение fillStyle или strokeStyle, оно становится новым цветом по умолчанию для всех следующих фигур.

Цвет сохраняется

Каждая новая фигура использует последний установленный цвет. 

ctx.fillStyle = "red";
// фигуры будут красными

ctx.fillStyle = "blue";
// следующие фигуры будут синими
Важно: если следующая фигура должна иметь другой цвет, свойство нужно изменить заново.

Форматы задания цвета

Цвет можно записывать разными способами. Canvas поддерживает стандартные значения CSS-цветов.

Один цвет — разные записи

Все эти варианты создают один и тот же оранжевый цвет: 

ctx.fillStyle = "orange";

ctx.fillStyle = "#FFA500";

ctx.fillStyle = "rgb(255 165 0)";

ctx.fillStyle = "rgb(255 165 0 / 100%)";

В motion design

Цвет — это не только визуальный стиль, но и инструмент управления вниманием зрителя.

  • выделять важные объекты;
  • создавать визуальную иерархию;
  • управлять восприятием композиции.
Главная идея: в анимации цвет может направлять взгляд зрителя так же, как движение и композиция.

Прозрачность (Transparency)

В Canvas можно рисовать не только полностью непрозрачные, но и полупрозрачные объекты.

Для этого есть два основных способа:

globalAlpha

Задаёт общий уровень прозрачности для всех последующих объектов.

Прозрачность в цвете

Прозрачность можно задать непосредственно через fillStyle или strokeStyle.

Свойство globalAlpha

Свойство globalAlpha задаёт общий уровень прозрачности для всех объектов, которые будут нарисованы после его установки. 

ctx.globalAlpha = transparencyValue;

0.0

Полностью прозрачный объект.

1.0

Полностью непрозрачный объект.
Значение по умолчанию. 

ctx.globalAlpha = 0.5;

Все последующие фигуры будут отображаться с прозрачностью 50%.

Прозрачность через цвет

Часто удобнее задавать прозрачность отдельно для каждой фигуры, указывая её непосредственно в цвете. 

ctx.strokeStyle = "rgb(255 0 0 / 50%)";

ctx.fillStyle = "rgb(255 0 0 / 50%)";

Как это работает?

Последний параметр функции rgb() отвечает за прозрачность именно этого цвета.

rgb(255 0 0 / 50%) → красный цвет с прозрачностью 50%
Преимущество: можно менять прозрачность конкретной фигуры, не затрагивая остальные.

Значения прозрачности

Прозрачность можно задавать двумя способами:

В процентах

От 0% до 100%.

rgb(255 0 0 / 50%)

Десятичным числом

От 0.0 до 1.0.

rgb(255 0 0 / 0.5)
Прозрачность помогает создавать более мягкие переходы, эффект наложения объектов и ощущение глубины — приёмы, которые часто применяются в анимационной графике и интерфейсной анимации.

Стили линий (Line Styles)

Canvas позволяет настраивать внешний вид линий с помощью нескольких свойств.

Форма и толщина

  • lineWidth — толщина линии
  • lineCap — форма окончания линии
  • lineJoin — форма соединения линий в углах
  • miterLimit — ограничение длины острого угла

Пунктирные линии

  • getLineDash() — получить шаблон пунктира
  • setLineDash() — задать шаблон пунктира
  • lineDashOffset — смещение начала узора
Главная идея: эти свойства позволяют управлять не только цветом линии, но и её толщиной, формой, углами и пунктирным узором.

Толщина линии (lineWidth)

Свойство lineWidth определяет толщину линии.

ctx.lineWidth = value;

По умолчанию

ctx.lineWidth = 1;

Толщина измеряется в условных единицах Canvas и должна быть положительным числом.

Пример

ctx.lineWidth = 8;

Все последующие линии будут рисоваться толщиной 8.

Особенности отображения линий

Линия рисуется по центру заданного пути. Поэтому положение координаты влияет на то, как линия попадёт на пиксели экрана.

Чёткая линия

Координата проходит по границе физических пикселей.

ctx.lineWidth = 1;
ctx.moveTo(20, 50);
ctx.lineTo(280, 50);
ctx.stroke();

Размытая линия

Центр линии оказывается между физическими пикселями.

ctx.lineWidth = 1;
ctx.moveTo(20, 50.5);
ctx.lineTo(280, 50.5);
ctx.stroke();
Почему? При координате 50 линия толщиной 1 px оказывается между пикселями симметрично. При 50.5 её центр смещается относительно пиксельной сетки, и браузеру приходится распределять цвет между соседними пикселями.

Форма окончания линии (lineCap)

Свойство lineCap определяет, как выглядят концы открытых линий.

ctx.lineCap = type;

butt

Плоский край.
По умолчанию.

round

Закруглённый конец.

square

Квадратный конец, который немного выходит за пределы линии.

Значения lineCap

butt

Линия заканчивается точно в конечной точке.

round

На конце добавляется полукруг с радиусом, равным половине толщины линии.

square

На конце добавляется квадрат, выступающий за конечную точку примерно на половину толщины линии.

Важно: различия между вариантами особенно заметны при использовании толстых линий.

Где работает lineCap

Свойство lineCap влияет только на начало и конец открытой линии.

Открытый путь

У линии есть отдельные концы, поэтому их внешний вид определяется свойством lineCap.

Замкнутый путь

closePath();

Отдельных концов уже нет — сегменты соединяются между собой. Внешний вид углов определяется свойством lineJoin.

Запомните: lineCap отвечает за концы открытых линий, а lineJoin — за соединения линий в углах.

Градиенты (Gradients)

Помимо обычных цветов, в Canvas можно использовать градиенты для заливки фигур и их контуров.

CanvasGradient

Градиент создаётся как отдельный объект CanvasGradient, который затем присваивается свойствам fillStyle или strokeStyle. 

ctx.fillStyle = gradient;
ctx.strokeStyle = gradient;
Важно: сначала создаём градиент, затем добавляем в него цвета и только после этого используем его как стиль рисования.

Типы градиентов

Canvas поддерживает три типа градиентов:

Линейный

Linear Gradient

Плавный переход цвета по прямой линии.

Радиальный

Radial Gradient

Переход цвета от одной окружности к другой.

Конический

Conic Gradient

Переход цвета вокруг центральной точки по кругу.

Каждый тип создаётся своей функцией Canvas.

Создание градиентов

Линейный градиент

ctx.createLinearGradient(
  x1, y1, x2, y2
);

Начало градиента задаётся точкой (x1, y1), конец — (x2, y2).

Радиальный градиент

ctx.createRadialGradient(
  x1, y1, r1,
  x2, y2, r2
);

Градиент строится между двумя окружностями с разными центрами и радиусами.

Конический градиент

ctx.createConicGradient(angle, x, y);

Цвета распределяются вокруг центральной точки по окружности, начиная с указанного угла.

Пример создания градиента

На этом этапе создаётся только объект градиента.

Линейный

const linearGradient =
  ctx.createLinearGradient(
    0, 0, 150, 150
  );

Радиальный

const radialGradient =
  ctx.createRadialGradient(
    75, 75, 0,
    75, 75, 100
  );
Но градиента пока не видно.

Чтобы он отображался, в него необходимо добавить цветовые точки.

Цветовые точки (addColorStop)

Цвета в градиенте задаются методом addColorStop(). 

gradient.addColorStop(position, color);

position

Положение цвета в градиенте — от 0.0 до 1.0.

  • 0.0 — начало градиента
  • 0.5 — середина
  • 1.0 — конец

color

Любой допустимый CSS-цвет.

gradient.addColorStop(
  0.5,
  "orange"
);
Цветовая точка определяет, какой цвет должен находиться в конкретной позиции градиента.

Формирование градиента

В градиент можно добавить любое количество цветовых точек.

Простой переход

gradient.addColorStop(0, "white");
gradient.addColorStop(1, "black");
  • 0 — белый
  • 1 — чёрный

Больше цветовых точек

Чем больше цветовых точек используется, тем сложнее и интереснее можно сделать переход.

В motion design градиенты часто применяются для создания объёма, глубины и более выразительного визуального оформления объектов.

Полный пример: линейный градиент

Создадим градиент, добавим цветовые точки и подготовим его для заливки прямоугольника.

1. Создаём градиент

const gradient =
  ctx.createLinearGradient(
    0, 0,
    300, 0
  );

Начало градиента — точка (0, 0), конец — (300, 0). Поэтому цвет будет изменяться слева направо.

2. Добавляем цветовые точки

gradient.addColorStop(0, "blue");
gradient.addColorStop(1, "red");

В начале градиента будет синий цвет, в конце — красный.

Используем градиент

После создания градиента его можно использовать как значение свойства fillStyle.

3. Назначаем градиент

ctx.fillStyle = gradient;

4. Рисуем фигуру

ctx.fillRect(
  20, 20,
  300, 100
);

Результат

Полная последовательность: создать градиент → добавить цвета → назначить fillStyle → нарисовать фигуру.
Задание: измените цвета и добавьте третью цветовую точку в позиции 0.5.

Паттерны (Patterns)

Кроме обычных цветов и градиентов, Canvas позволяет использовать паттерны — изображения, которые повторяются и образуют текстуру.

Что такое паттерн?

Паттерн использует изображение как повторяющийся элемент.

Из множества повторений изображения получается единая текстура.

Где применяется?

  • фоны;
  • декоративные элементы;
  • повторяющиеся узоры;
  • текстуры объектов.
Главная идея: вместо одного цвета или градиента фигура может использовать изображение, повторяющееся по заданному правилу.

Создание паттерна

Паттерн создаётся с помощью метода createPattern().

ctx.createPattern(image, type);

image

Изображение, которое станет основой паттерна.

type

Определяет, как изображение будет повторяться.

Использование паттерна

ctx.fillStyle = pattern;
ctx.strokeStyle = pattern;

Паттерн можно назначить fillStyle или strokeStyle — так же, как цвет или градиент.

Режимы повторения

Параметр type определяет, как изображение будет повторяться.

repeat

Повторяется по горизонтали и вертикали.

repeat-x

Повторяется только по горизонтали.

repeat-y

Повторяется только по вертикали.

no-repeat

Изображение используется только один раз, без повторения.

Пример: createPattern(img, "repeat-x") создаст горизонтальную последовательность изображений.

Пример использования

Сначала загружаем изображение, затем создаём на его основе паттерн.

const img = new Image();

img.src = "some-image.png";
const pattern = ctx.createPattern(
  img,
  "repeat"
);
ctx.fillStyle = pattern;

Что произойдёт?

После назначения fillStyle все фигуры, которые будут рисоваться с помощью fill(), будут заполняться выбранным паттерном. 

ctx.fillRect(20, 20, 300, 150);
По аналогии: паттерн можно использовать и для контура, назначив его через strokeStyle.

Важное замечание

Перед созданием паттерна необходимо дождаться полной загрузки изображения.

Почему это важно?

Если вызвать createPattern() до того, как изображение загрузится, паттерн может отобразиться некорректно или не появиться вовсе.

Та же логика с drawImage()

Это правило также действует при использовании метода drawImage():

1. Загрузить изображение
→
2. Использовать для рисования
Правило: сначала загружаем изображение, затем используем его для создания паттерна или рисования.

Пример использования паттерна

Изображение для паттерна находится в папке img рядом с HTML-файлом.

Полный пример

const img = new Image();

img.onload = () => {
  const pattern = ctx.createPattern(
    img,
    "repeat"
  );

  ctx.fillStyle = pattern;

  ctx.fillRect(
    20, 20,
    600, 500
  );
};

img.src = "img/pattern.jpg";

Что происходит?

  1. Создаём объект Image.
  2. Ждём загрузки изображения через onload.
  3. Создаём паттерн через createPattern().
  4. Назначаем его в fillStyle.
  5. Рисуем прямоугольник.

Путь к изображению:

img/pattern.jpg
Обратите внимание: createPattern() вызывается внутри onload, поэтому изображение гарантированно успевает загрузиться.

Тени (Shadows)

В Canvas можно добавлять тени к фигурам, линиям и тексту. Это помогает сделать изображение более объёмным и выразительным.

Основные свойства

  • shadowOffsetX — смещение по горизонтали
  • shadowOffsetY — смещение по вертикали
  • shadowBlur — размытие тени
  • shadowColor — цвет тени

Пример

ctx.shadowOffsetX = 10;
ctx.shadowOffsetY = 10;
ctx.shadowBlur = 15;
ctx.shadowColor = "rgba(0, 0, 0, 0.5)";

Смещение тени

Свойства shadowOffsetX и shadowOffsetY определяют положение тени относительно объекта. 

ctx.shadowOffsetX = 10;
ctx.shadowOffsetY = 10;

Направление

  • shadowOffsetX — горизонтальное смещение
  • shadowOffsetY — вертикальное смещение

По умолчанию оба значения равны 0.

Положительные и отрицательные значения

  • положительное X → вправо
  • отрицательное X → влево
  • положительное Y → вниз
  • отрицательное Y → вверх

Размытие тени

Свойство shadowBlur отвечает за мягкость тени.

ctx.shadowBlur = 15;

Малое значение

При 0 тень имеет чёткие границы. Чем меньше значение, тем жёстче выглядит тень.

Большое значение

Чем больше значение shadowBlur, тем более мягкой и размытой становится тень.

0 → чёткая    15 → мягкая    30 → сильно размытая

Цвет тени

Свойство shadowColor задаёт цвет тени.

ctx.shadowColor = "rgba(0, 0, 0, 0.5)";

CSS-цвет

Можно использовать любые допустимые CSS-цвета. 

ctx.shadowColor = "red";

Прозрачный цвет

Особенно удобно использовать rgba() с прозрачностью. 

ctx.shadowColor =
  "rgba(0, 0, 0, 0.5)";
По умолчанию цвет тени — полностью прозрачный чёрный. Поэтому без изменения shadowColor тень не будет видна.

Рисование текста

Canvas позволяет рисовать текст прямо на холсте.

fillText()

Текст с заливкой

strokeText()

Только контур текста

Два основных метода: один отвечает за заливку текста, другой — за его контур.

Метод fillText()

Метод fillText() выводит текст, используя текущий цвет заливки fillStyle. 

ctx.fillText(text, x, y);

Пример

ctx.font = "48px serif";
ctx.fillText("Hello world", 10, 50);
Результат:
Hello world

Метод strokeText()

Метод strokeText() рисует только контур символов, используя текущий цвет линии strokeStyle. 

ctx.strokeText(text, x, y);

Пример

ctx.font = "48px serif";
ctx.strokeText("Hello world", 10, 50);
Результат:
Hello world

Настройка шрифта: font

Внешний вид текста задаётся свойством font.

ctx.font = "48px serif";

Синтаксис полностью совпадает со свойством font в CSS.

По умолчанию: 10px sans-serif

Можно изменять размер, семейство шрифтов, начертание и другие параметры так же, как в CSS.

Выравнивание текста

Canvas позволяет управлять положением текста относительно заданной точки.

textAlign

Определяет горизонтальное выравнивание текста. 

const canvas = document.querySelector("#textCanvas");
const ctx = canvas.getContext("2d");

ctx.font = "32px serif";
ctx.textAlign = "center";

ctx.fillText("Hello world", 250, 90);
Что происходит? При textAlign = "center" координата x = 250 указывает на центр текста.

Базовая линия текста

Свойство textBaseline определяет, относительно какой линии располагается текст по вертикали. 

ctx.font = "32px serif";
ctx.textBaseline = "middle";
ctx.fillText(
  "Hello world",
  250,
  70
);

Основные значения

top — верхний край текста совпадает с координатой y.
middle — середина текста совпадает с координатой y.
alphabetic (установлен по умолчанию) — координата y задаёт базовую линию символов.
bottom — нижний край текста совпадает с координатой y.

Направление текста

Свойство direction определяет направление написания текста.

ctx.font = "32px serif";
ctx.direction = "rtl";
ctx.fillText(
  "مرحبا بالعالم",
  450,
  70
);

Возможные значения

ltr — слева направо
rtl — справа налево
inherit — от родителя
По умолчанию: inherit

Если в качестве изображения используется SVG-файл, в корневом элементе <svg> рекомендуется явно указывать width и height.

Без размеров

<svg
  viewBox="0 0 300 200"

Размер изображения может быть определён не так, как ожидается при работе с Canvas.

Почему это важно?

Сохранение и восстановление состояния Canvas

При создании сложной графики часто приходится временно менять настройки рисования.

Главная идея: можно временно изменить настройки Canvas, а затем вернуться к предыдущим.

Что сохраняет save()

Метод save() сохраняет текущее состояние контекста Canvas.

Трансформации
смещение, поворот, масштаб
Стили
цвет линий и заливки
Прозрачность
globalAlpha
Текст
шрифт и параметры текста
Тени
параметры и настройки теней
Clipping path
путь обрезки 
ctx.save();

// Здесь можно менять настройки
ctx.fillStyle = "red";
ctx.globalAlpha = 0.5;
// ...
ctx.restore();
Результат: после restore() настройки возвращаются к состоянию, которое было сохранено.

Принцип работы: стек состояний

Canvas хранит сохранённые состояния в виде стека.

save()
Сохраняет состояние
→
Состояние 3
Состояние 2
Состояние 1
Стек состояний
→
restore()
Берёт последнее состояние
ctx.save();       // состояние 1

ctx.save();       // состояние 2

ctx.restore();    // возвращаемся к состоянию 2
ctx.restore();    // возвращаемся к состоянию 1
Правило: состояния восстанавливаются в обратном порядке — последнее сохранённое возвращается первым.
